# 人工确认的多音字词组覆盖（在 zhcn-g1.ctb 的 always 词面之外追加）
#
# 收录两类人工确认、拆开必错且没有歧义的词。每行一个纯汉字词组。
# 1) 单字默认读音是姓氏/生僻读音：
#    单 的单独 sign 是 shàn（姓氏读音），拆成「单 用」会读成 shàn yòng；
#    整词保护后命中 always 规则，读 dān yòng。
# 2) 高频词典词，当前 jieba DP 因单字频率更高而拆开，拆开后读音会错：
#    为着/中和/着地/下地/中用（词频 209–622）。
# 低频且有上下文歧义的词（如 都会 的 dū/dōu 两读）故意不收录，避免误伤。
