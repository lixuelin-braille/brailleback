# 页码滑块：照系统桌面那排翻页提示

## 由来

用户拿手机桌面的底部翻页指示器做参照：读屏念出来是「第 1 页 共 7 页 滑块」。
他要阅读器这一块也长成这样——**页码说话，行数不说话**。

上一版这一块是「第 N 行 / 共 M 行，滑块」，页码反而不进朗读（当时他明确要求
滑块里不要页码）。这次等于把两者对调：页码进滑块、行数退出朗读。

## 现在的样子

- 滑块文字与朗读：`第 N 页 共 M 页`（`braille_reader_page_scrubber`），
  节点类型仍是滑块，一格一页；读屏念「第 N 页 共 M 页，滑块」。
- 双击滑块 → 「跳到第几页」数字输入（直接复用既有的 `ReaderDialog.Goto` 与
  `onGotoConfirmed`，不另造弹窗）。
- 触摸：按在滑轨上就跳到对应页，横向拖一页一页跟手；几何仍是
  「文字在左、滑轨接在后面」，`trackStartPx` 由 Canvas 与 `pointerInput` 共用。
- 上方小字只留段号（`第 43 段 / 共 25982 段`），只画不念；
  百分比去掉——它是页内行的比例，滑块改管页之后没有意义。
- 页内逐行仍有点显器 PREV/NEXT 硬件键（`moveLine`），不受这次改动影响。

## 代码落点

- `compose/BrailleReaderScreen.kt`：`LineScrubber` 改名 `PageScrubber`，
  参数 `lineIndex/lineCount` → `pageIndex/pageCount`；
  `ReaderUiState` 增加 `pageIndex/pageCount`；`ReaderLabels` 增加
  `pageScrubber/pageScrubberAction`。
- `BrailleReaderActivity.kt`：`updateUiState` 填 `pageIndex = currentUnit()`、
  `pageCount = totalUnits()`，`pageInfo` 收缩成段号；
  接线 `onPageSeek = gotoUnit`、`onPageEdit = showGotoDialog`。
- strings（两套）：`braille_reader_page_scrubber`、`braille_reader_page_scrubber_action`。
