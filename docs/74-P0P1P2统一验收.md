### 4.1 排布口径（代码 + 独立复算）

### 4.5 总览 / 细节 / 重叠 / 不丢墨 / 点规合法性

- **总览唯一降采样**：`downsample()` 为 `TactileViewport` 私有方法，**仅** `overviewBytes` 调用；`windowBytes` / `windowInk` 从全局点阵逐点直取，细节窗**只裁不缩放**。总览恰好一屏，字节长度 = `linesPerScreen × cellsPerLine`，带「总览」文本标记（不写进点位字节）。
- **重叠 1 点**：纵向次窗 `y0 = 首窗 y0 + height - 1`；横向次窗 `x0 = 首窗 x0 + width - 1`；共享行 / 列由 `windowInk` 从全局源逐位复制，不二次编码（`verticalOverlapOneRowCopiedFromSource` / `horizontalOverlapOneColumnCopiedFromSource`）。

- **三段式回归**：既有 `TactileStripSlicer.slice` → `StripBookBuilder.build` → `TactileStripPager` 成书 / 翻页顺序不变（`existingStripBookAndPagerStillHold`）。

## 5. P2 图形转正：独立复核

### 5.1 Normalizer 三态接生产路径（`TactileStrokeNormalizer.kt` / `TactileStripSession.kt`）

**三态与接线**

- 枚举 `StockNormalizerMode { OFF, AUTO, FORCE }`；`Config(mode, maxPasses=1, maxGrowthRatio=2.0)`。
- `Session.build(...)` 默认参数 `normalizerMode = StockNormalizerMode.AUTO`、`g1SplitCover = false`；归一器在 `dotGrid` 之后、`TactileStripSlicer.slice` 之前作用于全局点阵（`TactileStripSession.build` 第 47→49→57 行）。
- 分支行为（`normalize`）：
  - **OFF**：直接返回原数组本身，不复制、不改写。
  - **AUTO**：双门控——① `isPureLineArt`（墨占比 ≤ `MAX_INK_RATIO=0.35` 且 2×2 实心块占比 ≤ `MAX_SOLID_BLOCK_RATIO=0.08`）；② `hasFragmentationSign`（8 邻域孤立点 ≥ `MIN_ISOLATED_DOTS=8`，或 4 邻域单格连通域 ≥ `MIN_SINGLETON_COMPONENTS=5`）。任一不命中 → 逐字节返回原数组。
