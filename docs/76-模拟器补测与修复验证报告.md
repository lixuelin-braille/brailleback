### 1.1 测试钩子（DEBUG 专有，release 无入口）

新包为 debug 构建，含两个**仅 `BuildConfig.DEBUG` 分支可达**的调试钩子；release 构建该段不可达，不算产品入口：

| 钩子 | 命令 | extra |
|---|---|---|
| 数学 | `su 0 am start -n com.linxi.brailleback/.math.MathBrailleActivity --es formula_file <绝对路径>` | `formula_file` |
| 图片 | `su 0 am start -n com.linxi.brailleback/.tactile.TactileStripActivity --es image_file <绝对路径>` | `image_file` |

- 两个 Activity 均 `exported=false`，普通 shell uid 2000 直起报 SecurityException；userdebug 镜像 `/system/xbin/su` 可用，`su 0` 提权 uid 0 绕过 exported 校验拉起。
- 钩子直接 `File(path).inputStream()` 读文件；应用无存储权限，`/sdcard/Download/...` 走应用报 EACCES。已验证可读位置为应用外部私有目录 `/sdcard/Android/data/com.linxi.brailleback/files/`（数学 `math-cases/`，图片 `images/`）。
- 设备 FUSE 对长名做 8.3 截断（如 `01_geometry.png → 01_geom`），用例文件一律使用 ≤8 字符短名。

## 4. 遗留定性（P1-2 / P2-2）

### 4.1 P1-2　阅读器正文逐格重复汉字 —— 定性：仅屏显 / 映射层重复，入库副本未重复（修复需授权）

**现象（on-device 复现）**

- 源文件 `/sdcard/Download/cbs_test.txt`（3 行）：
  > 国家通用盲文测试。
  > 春天来了，万物生长。盲人朋友通过点显器阅读中文书籍。
  > 今天天气很好，我们一起学习盲文。
- 阅读器屏显（`dump/D1_reader_cbs.xml`）：`国国国国国国通通通通盲盲文文测测测试。。春春春天天天来来来了了，，万万生生生生生生。。…`，每个汉字按其占用盲文格数被重复多次。

**取证结论（只读核对，未改码）**

- 书架只在 SharedPreferences `bookshelf.xml` 存 URI / 文件名 / 扩展名 / 时间戳，**不存文本副本**；备份见 `dump/D1_bookshelf_prefs.xml`（单条 `content://…cbs_test.txt` 记录）。
- 应用私有 `files/`、`databases/` 均无入库文本拷贝（清单见 `dump/D1_app_private_dirs.txt`）；阅读器每次从 SAF URI 重读字节。
- 重复来自屏显 / 映射层：`ReaderSourceModel.reconstructSource` 按 braille  span 逐格 `append sourceText`，一个汉字音节映射多格时，同一字被每格重复一次。

**定性**：倾向“**仅屏显还原层重复，入库 / 源文本未重复**”。修复需改动 `ReaderSourceModel.kt`（受保护链路），本轮**只定位不改，等授权**。新三样本（单字行 / 长句 / 标点）屏显对比因 SAF 定向选取受限尚未全部跑成，列为待授权修复后复核项。

### 4.2 P2-2　多行三段式会话失败 —— 定性：多行解码 / 成书链路缺陷，非资产或格式问题

**对照证据（同一设备、同一 harness）**

| 样本 | 40×1 单行视口 | 40×4 多行三段式 |
|---|---|---|
| g1.png（自有 PNG，400×400） | PASS，总览出图 | FAIL，“图片解码失败或格式不支持…” |
| g1.bmp（同图 BMP） | PASS，总览出图 | FAIL，同一报错 |
| t1.png（自有竖图 300×900，三横带） | — | FAIL，同一报错 |

**判定**：

- 同一 PNG 单行可解、多行失败；同名 BMP 多行同样失败；不同内容竖图多行同样失败。**排除“PNG 资产 / 格式问题”**，指向多行链路独有的环节（切片 / 归一 / 封面封底翻译桥 / 成书打包）。
- 单行 `buildViewport` 与多行 `TactileStripSession.build` 共用 `loadGrayImage + dotGrid`；多行额外走 `TactileStrokeNormalizer` → `TactileStripSlicer` → 封面 / 封底 `wrapIntoScreens`（翻译桥）→ `StripBook` 组装。
- Activity `rebuild()` 的 `catch (e: Exception)` 把任何环节异常兜底为 `tactile_strip_fail_decode` 通用文案，**未记录异常类型 / 消息**；crash 缓冲为空（异常被捕获，未抛到系统）。本轮无法仅凭 on-device 日志定位到具体环节，需修复轮在 catch 内落日志或在稳定 harness 下分步单测。
- 旧视口控件在失败后未被清空（代码“失败不刷新上一版”，`TactileStripActivity.kt` rebuild 路由）。

**待修方向（只读建议，未动手）**：在 Session.build 各阶段补异常日志；优先排查封面 / 封底翻译桥在无点显 / 翻译服务时 `toBraille` 是否抛错（视口图例桥自身有 try/catch 回退空屏，Session 的 `wrapIntoScreens` 未逐行包裹）。
