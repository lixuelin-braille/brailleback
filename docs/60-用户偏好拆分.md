## 拆出哪些文件、各自职责

- **`BrailleUserPreferencesMigration.kt`**：SharedPreferences 文件名入口（`braille_keyboard`）、历史版本号迁移（AAS12.0 → 16.2 共五段）、迁移用旧键名换算、测试用版本重置。所有 getter 前置调用的 `getSharedPreferences` 在这里，迁移状态 `currentVersion` 也只归它管。
- **`BrailleUserPreferencesTranslator.kt`**：输入/输出盲文码、首选语言列表、contracted（缩写）模式、翻译工厂与按码定制器（韩文/通用）。BK 与 BD 共用的翻译偏好都在这。
- **`BrailleUserPreferencesKeyboard.kt`**：盲文键盘侧——累积输入、反点位、布局模式与手机/平板校准点、教程是否首启弹出、退出键盘/选项对话框计数、更换手势引导不再提示。
- **`BrailleUserPreferencesDisplay.kt`**：点显器侧——自动换行、屏幕悬浮层、输入/输出码切换提示、导航命令不可用提示、USB 连接对话框、反翻页按钮、光标闪烁间隔、定时消息时长、自动滚动时长与自动调节、弹窗公告与历史、字幕与字幕教程时间戳、手势动作映射表、命令变更对话框。

## 为什么这么切

按"键前缀 + 使用场景"切：`pref_brailleime_*` 归键盘，`pref_bd_*` 归点显器，翻译码 BK/BD 共用归翻译域；迁移单独成文件，因为它持有跨版本状态，且被每一次偏好读写前置调用。没有为行数硬切：翻译域里输入码/输出码/首选语言/工厂本来就是一条链，放在一起避免跨文件来回跳。
