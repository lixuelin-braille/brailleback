## 2 工作区与分支占用（硬约束）

**一个 worktree 同一时刻只许一个角色动手。** 违反这条，多人改同一个工作树会互相踩掉未提交改动。

| 弧段 | 角色 | 工作区 | 分支 | 允许 git 操作 |
|:---|:---|:---|:---|:---|
| 主线 | ENGINE | `D:\软件\brailleback盲文` | `main` | merge / commit |
| 硬件 | HARD | `D:\bb-wt\sunshine` | `feat/sunshine-docx` | commit |
| 测试 | TEST | `D:\bb-wt\testbuild` | `test/build-all-20261126` | 只读 |
| 文档 | PM / RESEARCH | `main` 的 `docs/` | 不提交 | 无 git |

- 其余 worktree（`auto`/`diag`/`docs119`/`fix`/`metec`/`pages`/`perf`/`release`/`selfcheck`）本轮**冻结**，谁也不许进。
- 两个文档角色只在 `docs/` 下新建文件，**一律不执行 `git add` / `git commit` / `git checkout`**，三大目录的未跟踪文件由收口环节统一提交。

### 2.1 并行槽位（不是并行角色）

三条硬瓶颈都在资源，不在人手：真机只有一台、单机单 Gradle、main 只有一条合并线。所以扩的是**槽位**，不是角色。

- **main 单写者**：只有集成守门人能对 `main` 执行合并，并由守门人自己跑完四道门禁；其余角色只在自己的 worktree 提交，要进 main 等下一轮派单。本轮守门人是 ENGINE。
- **真机时段表**：真机同一时刻只归一个角色。本轮 ENGINE 独占；真机上屏这类必须点显器在线的验证，排在硬件在线时段，没有就标「未验」，不许拿模拟器结论顶替。
- **模拟器常驻槽**：UI 冒烟与 11 步取证固定走 AVD `brailleback_api35`，不占真机；单机单 Gradle，同一时刻只许一个构建任务，并发会互踢 build 目录。
- **不扩员的理由**：六个角色已经贴着上述三条瓶颈，再加人只是让更多人在同一台真机、同一个 Gradle 上排队。
- **扩员触发条件（写死，不临时决定）**：开 N9 拍照即读、或开注 1 反向翻译（都要调研+引擎+安卓三线并行）；出现第二台真机；进入发版期需要专职打包与灰度。任一成立才加第 7 个角色，否则维持六个。

### 2.2 推送与备份（2026-11-27 用户批准，取代原先的「一律不 push」）

**允许快进推送 `main` 与功能分支到 `origin` 用于备份；仍然禁止 force push、禁止改写历史、禁止 rebase 已推送分支、禁止向他人分支推送。**

- 远端：`origin = git@github.com:lixuelin-braille/brailleback.git`。
- 每次合并收口后推一次 `main`，并打一个 `backup/roundN-<hash>` 锚点 annotated tag 一并推上去。
- 推送前必须 `git status` 干净、四道门禁已过；推送只做快进（`git push origin main` 不带 `--force`、不带 `+`）。
- 违反这条的后果比不推更重：远端一旦被改写，外部贡献者手里的克隆就全废——所以「能推」不等于「能改写」。

### 7.1 release 签名密钥：复用现有那把，不新做

- 理由：已满足「仓库外、不入库、4096 位、10000 天」全部口径；121 的 `keystore.properties` 已指向它，接线是现成的；重做等于拆掉已接好的线、多造一把不可回收的钥匙。
- 边界：`.gitignore` 第 76–78 行已覆盖 `keystore.properties`、`*.jks`、`*.keystore`；口令只存仓库外两个文件，三处哈希已核对一致。
- 事实澄清：54.18 MB 那个 release 包确由这把钥匙签过（apksigner 证书指纹一致），主仓库 21.1 MB 包仍是 debug 签名；目前**未证实有任何对外发布包**用过它，所以首次对外发布前必须先完成分介质备份。
- 记录：`docs/133-发布签名密钥决定与保管.md`。

### 7.2 N2 真值对语料：比对台先筛，人只判存疑项

- 决定：不做 500 句全人工。三道筛——工具判「一致」直接入语料（`source: tool`）；差异且属已知口径差入语料（`source: tool`，带 `rule_basis`）；只有「差异且口径不明」进存疑池交人工（`source: human`）。
- 负担口径：500 句三档折算 1.5 / 2.7 / 4.6 小时，由抽样比例决定，产品负责人按这个数字选档。
- 风险声明：工具筛本身可能漏错，抽检比例越低漏检概率越高；未被人工判过的条目不进「防错译」档。
- 记录：`docs/131-N4桌面比对台可行性报告.md`。
