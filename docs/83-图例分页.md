# 83 - 图例分页（单行设备也看得完整）

- 日期：2026-11-25
- 与 [81](./81-视口按键交给点显器.md) / [82](./82-细节态独占点显器.md) 同一批视口体验收尾

## 1. 问题

视口模式只在单行设备走，`linesPerScreen == 1`。图例页的源行至少三条
（「检测到 n 处图内标注」「以下为标注位置，未识别文字内容」+ 每个候选一行），
一屏只有一行 → 前面的候选位置全被截掉，图例等于只看得到一句「检测到 n 处」。

这是 79 号文 §3 挂着的那条「图例候选超一屏分页」，真机前先把逻辑补齐。

## 2. 改动

- `TactileLegendPage` 增加两个纯函数：
  - `pageCount(lineCount, linesPerScreen)`：向上取整，行数 0 也算 1 屏；
  - `pageLines(lines, page, linesPerScreen)`：按屏切行，页码越界钳到首 / 末屏，不抛异常；
    一屏装得下时原样返回，不做多余切分。
- `TactileStripActivity`：
  - 新增 `vpLegendPage` 状态；进图例固定回第 0 屏，关图例清页；
  - `legendPageCount` / `legendBytes(vp, page)` 按页取点位，页签与状态行带「图例 2/3」；
  - `vpLegendNavigate(delta)` 翻页，越界短震 + 播报「已是图例第一屏 / 最后一屏」；
  - 点显器按键：图例态下回车（或再按图例键）退回图形，四个方向键翻页（左/上=上一页，右/下=下一页）；
    此前是「图例态按任何键都直接退出」，对多候选图例等于没法看；
  - 手机侧：音量键 / DPAD 同为翻页；图例超一屏时多出「图例上一页 / 下一页」两个按钮，
    一屏装得下就不摆这两个空按钮。
- 文案（中英各一份）：`tactile_vp_legend_prev`、`tactile_vp_legend_next`、
  `tactile_vp_legend_page_label`、`tactile_vp_status_legend_page`、
  `tactile_vp_legend_first_page`、`tactile_vp_legend_last_page`。

## 3. 验证

- `TactileLegendPageTest` 增加 3 例：单行设备一行一屏且顺序正确；一屏装得下时不切分；
  页码越界钳制。
- `:brailleback:testDebugUnitTest` 全绿，`lintDebug` 0 error，`assembleDebug` 成功，
  已 `install -r` 到手机；真机未验（要看图例翻页还得插点显器）。

## 4. 待真机

- 单行设备上，图例每屏只一行，翻页频率会比较高；若真机觉得慢，可考虑「每屏两行压缩成一行」
  或缩短图例措辞（例如位置行改成「带3方5」），这类文案压缩留到真机反馈后再做。
