# 把「百分之 X」从滑块朗读里去掉：改用滚动语义

## 问题

真机朗读是「百分之 0。 第 1 行 / 共 20 行 滑块」——百分比排在前面，压不掉。

查到的结论：这是读屏对**范围型控件**的固有播报，不是我们输出的文本。

- vivo 的 TalkBack 使用教程把滑块播报格式写成 `xx%-屏幕亮度-滑块-向上或向下滑动即可调整`；
- 华为鸿蒙无障碍文档同样把「默认为百分比格式」写成默认行为；
- `stateDescription` 在官方 TalkBack 上会替代百分比，但小米增强 TB / 天坦不看它，
  直接按 `AccessibilityNodeInfo.getRangeInfo()` 算并念出来；
- 没有任何 App 侧 API 能"关掉百分比"，只有不声明范围语义这条路。

## 改法

`ScrubberBar` 的语义块从「滑块」换成「可滚动」：

```kotlin
// 原来：progressBarRangeInfo + setProgress  → 读屏算百分比
verticalScrollAxisRange = ScrollAxisRange(
    value = { index.toFloat() },
    maxValue = { maxIndex.toFloat() },
    reverseScrolling = false,
)
scrollBy { _, delta ->
    val step = if (delta > 0f) 1 else -1
    onSeek((index + step).coerceIn(0, maxIndex))
    true
}
```

代价与预期：

- 读屏大概率改念「可滚动」之类的滚动提示，不再有「百分之 X」，也大概率不再说「滑块」；
- 上下滑仍然一格一格调，方向按 `reverseScrolling = false` 取「向后滚动 = 加一格」；
- `contentDescription` / `stateDescription` 仍是「第 N 页 共 M 页」「第 N 行 / 共 M 行」，
  聚焦时能念全；每次调节后会不会自动念出新位置，取决于读屏实现。

## 状态

- 编译通过、已装真机；**没有**用耳朵验证（adb 模拟不了读屏手势，
  且改完时用户正在用别的应用，没有抢前台）。
- 需要用户听这四点：是否还有百分比；是否改念「可滚动」；上下滑是否一格一格且方向正确；
  调节后有没有念出新位置。
- 若不可接受：把语义块退回 `progressBarRangeInfo` 版本（git 上 `f524c05` 即上一版）。
