## 1. 方案对比与推荐

### 1.1 候选方案

| 维度 | ① JSON 表 + Kotlin MathML 遍历器（推荐） | ② 表转 liblouis 数学表 | ③ 构建期 Brailix 预翻译静态串 |
| --- | --- | --- | --- |
| 实现路径 | 中文数学表 + cells/numbers/letters 离线生成 Kotlin 常量入库；纯 Kotlin DOM 遍历器按 MathML 标签出盲文；输出 Unicode 串 + 点位 `IntArray`；`<mtext>` 中文走可注入提供者桥接既有 TranslatorService | 把 symbols/functions/structures/digits 翻成 liblouis `.utb/.ctb`，登记进 `service/tablelist.xml`，由既有 TranslatorService 选表翻译 | 构建脚本离线调 Brailix，把公式翻成静态盲文串（Kotlin/JSON）入库；运行期只查快照表，不做结构解析 |
| 成本 | 已落地：math 包 6 个 Kotlin 文件 + 1 个测试类；表生成脚本为一次性离线工具 | 需新写 liblouis 数学表语法（分类标记、分数/根号/上下标结构），并改 service 选表与登记逻辑 | 需维护公式清单、预翻译流水线与快照产物；动态 / 用户自输公式无法覆盖 |
| 风险 | 表内容随 Brailix cn_current 冻结；未支持标签显式抛异常；少量规则为子集简化（见第 5 节） | 数学结构语义映射进 liblouis 表语法损耗大；混排选表规则复杂；**要动受保护文件**，回归风险高 | 工具期引入 Python 链路；表外输入无产物；与「用户粘贴受控公式」的交互形态不匹配 |
| 可维护性 | 表与代码分离，换表重跑离线脚本；JVM 单测可离线逐条对齐 golden | 表属 liblouis 生态，但结构表达绕、调试依赖原生表 | 静态快照，公式变更必须重建，更新成本高 |

### 1.2 方案②为什么本轮只评估、不落地

任务约束明确：本轮 service 模块、liblouis 表、`tablelist.xml` 零改动，因此方案②仅作为后续
评估结论保留，不在本轮实施。

### 1.3 方案③的产物入库与重建方式（备查，未采用）

若日后走③：预翻译产物（盲文串 / 点位表）作为资源入库随 App 打包；公式集合变更时重跑离线

当场粘贴的新公式，故本轮不选。

### 1.4 推荐结论

采用 **①**：表随 App 打包、纯 Kotlin 解析、不碰受保护文件、JVM 可离线测试，中文自然语言部分

## 3. 编码口径

### 3.1 点位契约

- 每方一个字节 / 掩码：dot1=bit0 … dot6=bit5，与既有 `displayDots` 契约一致；
- 6 点：所有字节高位（bit6/bit7）恒为 0，测试有断言；
- 8 点：复用同一套 6 点点位，第 7/8 点保持 0，结构预留后续扩展；
- Unicode 输出：U+2800..U+28FF，字间隔为空方 U+2800。

### 3.2 支持的 MathML 标签

`math`、`mrow`、`mi`、`mn`、`mo`、`mtext`、`mfrac`、`msqrt`、`msub`、`msup`、
`msubsup`、`mroot`、`mfenced`、`mtable`、`mtr`、`mtd`、`mover`、`munder`、`munderover`。

其余标签（`mspace`、`mstyle`、`mprescripts`、`mstack`、`merror` 等）直接抛
`IllegalArgumentException`（带标签名），不静默产出错盲文。

### 3.3 输入语法

- **MathML**：粘贴 `<math>…</math>`；
- **受控线性写法**：字母 / 数字；`+ - = < > ≤ ≥ ± × ÷ ·`；逗号、小数点；
  `( ) [ ] { }`；`√`；上标 `^`、下标 `_`；分数 `/`。标识符后紧跟括号按函数调用解析
  （实参逗号分隔，如 `sin(x)`、`f(x,y)`）；`sqrt`（大小写不敏感）是 `√`/`<msqrt>` 的
  线性别名，支持 `sqrt(...)` 与 `sqrt x` 两种形态。线性子集不含矩阵 / 方程组 / 重音 /
  希腊直输，这些结构走 MathML 骨架（模板按钮即插 MathML）。
- 输入归一：中文输入法常把半角符号转成全角（`／ ＋ － ＝ （ ） ［ ］ ｛ ｝ ， ． ＜ ＞`），
  两条通道共用 `MathFullwidth` 归一映射；Unicode 减号 `−`（U+2212）与 ASCII `-` 互为别名，
  按表内规范减号出方。MathML 路径只归一文本节点，标签名与属性保持原样。
- **文件导入**：数学页「从文件导入公式」走 SAF（`text/*`、`application/xml`、
  `application/xhtml+xml`；`.mathml` 通常由 provider 按 text/xml 暴露）；UTF-8 读取，
  兼容 BOM 与 CRLF；上限 256 KB，超限整份拒绝（不截断，避免半条 MathML 标签）；空文件 /
  读取失败给状态提示，不自动触发转换。
- **类型嗅探**：填入前按内容判定——首个非空白字符为 `<` → MathML（整段 `<math>…</math>`
  或裸标签片段），否则 → 线性写法；与 `MathBraille.encode` 既有分派等价，20 条 golden 不回退。
  两者同时像 `<...>` 形态时，以「开头是 `<`」为准判 MathML。
- 不做公式 OCR、不读图片公式。

### 3.4 规则要点（对齐 Brailix cn_current 后端）

- 字母：class 前缀（小写 `⠰` / 大写 `⠠` / 希腊小写 `⠨` / 希腊大写 `⠸`）+ 裸字母；
- 函数名：`⠫`（indicator.symbol）+ 表内缩写；
- 数字：`⠼` 数字符号 + 基线数字；纯数字下标 / 指数用低位数字，不带 close；
- 分数：Antoine 单位数紧凑式 / 简化横杠式 / 复合括号式；
- 根号：open +（次根次数）+ indicator + 内容 + close；
- 运算符空格：按表内 `space_before` / `space_after` 出空方；分类标记由渲染层另发，
  不烘进裸区分点；
- **上下标同体 `msubsup`**：子级顺序 base → sub → sup，下标先于上标；纯数字脚本走低位数字
  且不带 close，字母脚本带 script.close；
- **次根 `mroot`**：输出 sqrt.open + 次数 + sqrt.indicator + 底数 + sqrt.close（次数在
  indicator 之前，对齐 Brailix `roots.py`）；
- **矩阵 `mtable`**：`<mo>(</mo><mtable/><mo>)</mo>` 序列识别为围栏矩阵；每行开合界符，
  单元内运算符前空方被 `matrix.op_prefix ⠐` 取代；行间断行 / 悬挂开合哨兵在直出路径渲染为空方；
- **方程组（cases）**：MathML 无 `mcases` 元素，本项目采用映射
  `<mrow><mo>{</mo><mtable>…</mtable></mrow>`（可带空 `<mo/>` 对应 `\right.`）；
  后端走 cases 调色板三段 `cases.first / middle / last`（`⠎ / ⠇ / ⠣`），逐行段前缀：
  首行 first、末行 last、中间行 middle；
- **重音 `mover/munder/munderover`**：base 后发 accent.over/under 方向标记；带
  accent_mark 的字符（`→ ←` = arrow，`¯ ― ‾` = bar）走 `accent.mark.<kind>.{single,double}`，
  base 字母数 ≥2 用 double；其余回落符号表 / 字母表；
- **希腊字母直输**：`<mi>α</mi>` 等按 greek class 发前缀 + 裸点位；
- `<mtext>` 中文：经 `ChineseBrailleProvider` 走既有 TranslatorService 桥；提供者为空或
  失败时逐字符数学表回退。

## 6. 入口与操作步骤

1. 书架页（既有「导入」「图片转点显」下方）点击 **「数学公式转盲文」**；
2. 在输入框粘贴 MathML（`<math>…</math>`），输入受控线性公式（如 `a^2+b^2=c^2`），或点下方
   模板按钮插入分数 / 根号 / 上下标 / 矩阵 / 方程组骨架，在光标处改写占位字母；也可点
   **「从文件导入公式」** 经 SAF 选 `.txt` / `.mathml` / `.xml` 文件，内容回填输入框（不自动转换）；
3. 点 **「转换」**：结果盲文串显示在下方，可被 TalkBack 朗读；
4. **「推到点显」**：把当前结果点位下发到连着的点显器；**「复制盲文」**：复制 Unicode 盲文到剪贴板；
5. 6 / 8 点切换在结果上方单选行（RadioButton 语义 + 选中态 stateDescription）。
