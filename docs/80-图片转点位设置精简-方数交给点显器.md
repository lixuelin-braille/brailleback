# 80 · 图片转点位：设置精简，方数交给点显器

> 日期：2026-11-25　改动：`TactileStripActivity`、`strings_tactile_viewport.xml`（中英各一份）
> 关联：[71](./71-单行设备视口模式.md)（视口）、[73](./73-触觉图例与标注候选.md)（图例）

## 1 原来难在哪

选图页从上往下是五组设置：一行方数（20/30/40 三选一）、行数（1–8 加减）、每格点数（6/8）、
线条归一（自动/关/强制）、G1 封面分层（开/关）。盲人用户要用点点划划一组组摸过去，
而这五组里真正跟「我这台机器」有关的只有方数和点数——方数本来就该由点显器告诉 App。

## 2 改了什么

| 项 | 之前 | 现在 |
|---|---|---|
| 一行方数 | 主界面三选一 | **默认跟随点显器**：连上后按设备上报的文本格数自动换行，主界面只显示一行说明「方数：跟随点显器（40 方）」 |
| 手动方数 | 主界面 | 收进「高级设置」，手动选了就不再跟随 |
| 行数 | 主界面加减 | 仍在主界面（原因见下） |
| 每格点数 6/8 | 主界面 | 仍在主界面（硬件属性，必须能选） |
| 线条归一三态 | 主界面 | 收进「高级设置」 |
| G1 封面分层 | 主界面 | 收进「高级设置」 |

首屏可扫读的东西从五组变成：选图按钮、图片摘要、方数一行、行数一行、点数两项、「高级设置」入口。
高级默认收起，展开后还是原来的单选行，读屏逐项可读。debug 注入（`cells_per_line` 等）仍然有效，
注入方数等同于手动指定、自动关掉跟随。

## 3 行数为什么没跟着自动

点显器这一层 API（`client` 模块的 `BrailleDisplayProperties`）只上报 `numTextCells`（一行方数），
**没有任何设备把行数送到这一层**。唯一的例外是无界（Wujie）在 GATT 里读到了 rows/cells，
但驱动只打了日志（`WujieGattConnection.kt:188`），没往属性里送。

要把行数也交给点显器，需要两步：
1. `BrailleDisplayProperties` 加 `numRows` 字段，客户端/服务端一起改；
2. 无界驱动把读到的 rows 填进去（其它驱动没有行数可填，仍然要回退到手动）。

这一步没做，本轮只把「确定能从设备拿到」的方数接了进来。
