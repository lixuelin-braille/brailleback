# 81 - 视口按键交给点显器（图例 / 上移 / 下移 / 左移 / 右移）

- 日期：2026-11-25
- 对应提交：`2058818`
- 前置：`71ef962`（80 号文，设置精简）

## 1. 诉求

单行设备的触觉图视口里，图例、上移、下移、左移、右移这几件事，要**优先用点显器自己的按键**
完成，不再每次都腾出手去摸屏幕按钮。

## 2. 硬件侧能拿到什么

`DisplayService.broadcastInputEvent()` 把点显器输入事件**广播给所有已绑定客户端**
（`mClients` 逐个 `onInput()`），所以视口页可以自己挂一份 `Display.OnInputEventListener`，
不会抢走服务侧既有分发。可用命令码（`client/.../BrailleInputEvent.kt`）：

| 命令码 | 值 | 常见物理键 |
|:---|:---|:---|
| `CMD_NAV_PAN_LEFT` | 5 | 平移键（左 / 后） |
| `CMD_NAV_PAN_RIGHT` | 6 | 平移键（右 / 前） |
| `CMD_NAV_LINE_PREVIOUS` | 1 | 上一行 |
| `CMD_NAV_LINE_NEXT` | 2 | 下一行 |
| `CMD_KEY_ENTER` | 70 | 回车 / 确定 |

注：`CMD_NAV_PAN_UP`/`CMD_NAV_PAN_DOWN` 在本仓库里是 5/6 的同值别名，没有独立上报通道，
所以纵向只能靠「上一行 / 下一行」键，不能指望平移键出四个方向。

## 3. 改动

- 新增 `tactile/TactileDisplayKey.kt`：纯查表 `actionFor(command)` → `Legend/Up/Down/Left/Right`，
  未映射命令返回 null（不吞键，打字点位键原样放过）。
- `TactileStripDisplay` 增加 `setOnInputEventListener()`，把监听挂到内部 `DisplayClient`。
- `TactileStripActivity`：
  - `displayKeyListener` 收到事件后 `runOnUiThread` 转 `onDisplayKey(command)`（客户端回调不在主线程）。
  - `onDisplayKey()` 只在 `viewport != null` 时生效；**图例屏下按任何已映射键都先退回图形页**，
    避免「在图例里按方向键毫无反应」。
  - `onDestroy` 先 `setOnInputEventListener(null)` 再 `close()`。
- 文案：连上点显器时视口区顶部出 `tactile_vp_keys_hint`（中英各一份），说明按键对应关系，
  屏幕按钮保留作备用。

映射表：

| 动作 | 点显器按键 |
|:---|:---|
| 左移 / 右移 | 平移键左 / 右 |
| 上移 / 下移 | 上一行 / 下一行 |
| 图例开合 | 回车 |

## 4. 验证

- 新增 `TactileDisplayKeyTest`（5 例）：锁三个方向键与回车键的命令码；`CMD_NONE` /
  `CMD_ACTIVATE_CURRENT` / 未知码一律不接管；`Action` 只允许五个取值。
- `:brailleback:testDebugUnitTest` 通过，`lintDebug` 0 error，`assembleDebug` 成功，
  debug 包已 `install -r` 到手机。

## 5. 未做 / 待真机

- 真机未验：键位到底上报哪几个命令码，取决于设备驱动（metec 40 方有线、清华 V3、无界各不同）。
  插上设备后在视口里按一遍即可确认；届时若某台设备的平移键上报的是横向别的码，
  改 `TactileDisplayKey.actionFor` 一处即可。
- 没做「进细节 / 回总览」的硬件键（`CMD_NAV_TOP` / `CMD_NAV_BOTTOM` 可用，但各设备是否有对应
  物理键不确定），留到真机确认键位后再加。
- 屏幕上的五个按钮暂时全留；真机确认硬件键稳定后，可以把它们收进「高级」减少焦点停靠数。
