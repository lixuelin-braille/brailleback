## 2. 视口设计

### 2.1 状态机与块定义

`OVERVIEW`（总览）→ `DETAIL`（细节）→ `LEGEND`（独立图例屏）；`backToOverview()` 从任意细节位置返回总览，选择框回到当前块位置。

- **总览**：整图多数表决压成一屏（`windowCols × bandRows`），是全流程**唯一**允许降采样的一页；`isOverview` / `overviewLabel="总览"` 与细节页严格区分，标记只走 TTS，不写进点位字节。
- **块**：总览选择框定义为一个**块**。块宽 = 整幅宽度（`cellsPerLine×2`）；块高 = 4 屏折算点行，`blockRows = 4 × bandRows`（8 点 16 点行、6 点 12 点行）。块内细节页数固定 **4 屏**；图尾剩余不足一块时，末块允许 1–3 屏，不跨出 4 屏。
- **细节**：从全局点阵**只裁不缩放**；`enterDetail()` 进入当前块第 1 屏，`nextPage()/prevPage()` 只在块内翻，到块首/块末返回 `BLOCK_START/BLOCK_END`；`nextBlock()/prevBlock()` 换到相邻块并回到该块首屏，到第一/最后一块返回 `FIRST_BLOCK/LAST_BLOCK`。横向仍按窗平移，边界 `LEFT/RIGHT`。窗格 `windowCols = cellsPerLine×2`、`bandRows = linesPerScreen×(8 点 4 / 6 点 3)`；字节长度恒为 `linesPerScreen × cellsPerLine`。
- **可断言接口**：`blockIndex`、`blockCount`、`blockPageIndex`、`blockPageCount()`，供单测与 UI 播报。
- **图例**：`TactileLegendPage.build(brailleLines, spec)` 整屏打包，独立一屏，不占用图形页。

### 2.2 块内翻页、块间移动与边界

- 细节态纵向：先 `prevPage/nextPage` 在块内翻；块首再上翻给 `BLOCK_START`、块末再下翻给 `BLOCK_END`；Activity 遇块末/块首自动退到 `prevBlock/nextBlock` 换块。块间到第一块给 `FIRST_BLOCK`、到最后一块给 `LAST_BLOCK`。
- 细节态横向：`panLeft/panRight` 按窗平移；受阻返回 `LEFT/RIGHT`，起点不变。
- 总览态：同一组导航键移动选择框（横向按方 = 2 点列，纵向按块 = `blockRows` 点行），出界钳到边缘并给边界信号。
- 相邻屏重叠 1 点（纵向 1 行、横向 1 列），重叠内容来自同一布尔源原样复制；理想边界附近有整行/整列无墨时，切缝落在空白处（复用 `TactileStripSlicer.blankSeam`），不强行重叠。

### 2.3 入口

书架「图片转点显」→ `TactileStripActivity`：
- `linesPerScreen == 1` → 视口模式；
- `linesPerScreen ≥ 2` → 原三段式（封面屏 → N 图形带页 → 封底屏），行为与文案不变。

## 3. 操作步骤与无障碍

### 3.1 触屏 / TalkBack（按钮均可聚焦可点击，不靠颜色或位置）

1. 选图 → 进入总览屏，播报「总览」+ 操作引导。
2. 总览态：「左移 / 右移 / 上移 / 下移」移动选择框 → 「进入细节」。
3. 细节态：上下键块内翻屏、块末/块首自动换相邻块，左右键横向平移；「返回总览」一键回总览；「图例」进独立图例屏，「返回图形」回到视口。

### 3.2 硬件键

| 按键 | 视口态 | 三段式态（多行设备） |
|---|---|---|
| DPAD 左 / 右 | 选择框 / 细节窗 左移 / 右移 | 上一页 / 下一页 |
| DPAD 上 / 下、音量上 / 下 | 块内上一屏 / 下一屏；块首/块末自动换相邻块 | 上一页 / 下一页 |

### 3.3 反馈

- 细节态播报「第 b/B 块，第 k/K 屏」（`blockIndex+1`/`blockCount`，`blockPageIndex+1`/`blockPageCount()`）。
- 到屏边界：20ms 短震 + TTS「左边到头 / 右边到头」；块内首/末屏播报「块首 / 块末」；块边界播报「已到第一块 / 已到最后一块」。震动能力不可用时静默降级，不阻断浏览。

## 6. 80×80 与关键夹具实测（单测断言值）

### 6.1 80×80 块结构（40 方 / 单行 / 8 点）

| 断言项 | 实测值 |
|---|---|
| 总览 | **1 屏**；`isOverview=true`；标记「总览」 |
| 版面折算 | `windowCols=80`、`bandRows=4`、`blockRows=16` |
| 块数 | `blockCount = ceil(80/16) = 5` |
| `enterDetail()` | `blockIndex=0`、`blockPageIndex=0`、`blockPageCount()=4` |
| 块内翻页 | 前 3 次 `nextPage()` `moved=true`；第 4 次 `moved=false`、边界 `BLOCK_END`、`blockPageIndex=3` |
| 末块屏数 | 第 5 块（index 4）`blockPageCount()` 在 **1..4** 区间 |
| 块间移动 | 第 0 块 `prevBlock()` → false、`FIRST_BLOCK`；`nextBlock()` ×4 到 index 4；再 `nextBlock()` → false、`LAST_BLOCK` |
| 整图细节屏数 | 5 块 × 每块 4 屏 × 横向 1 窗 = **20 屏**（块内每块 4 屏，不再摊成 27 条自由带） |

### 6.2 关键夹具

| 用例 | 版面 | 实测结果 |
|---|---|---|
| 短图块屏数 | 80×12，40 方 / 单行 / 8 点 | `blockCount=1`；`blockPageCount()=4`，落在 **1..4** 区间 |
| 左 / 右边界 | 16×8，4 方 / 8 点 | 起点列 0 再左移 → false、`LEFT`；最右窗再右移 → false、`RIGHT`，起点不变 |

| 横向重叠 | 15×3 满墨 | 相邻窗重叠 **1 列**；重叠列逐位一致 |
