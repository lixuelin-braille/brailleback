# 114 - 待修：正文续装不触发

> 日期：2026-11-26
> 状态：**本轮只记录，不修**。缺陷事实取自 [109-拆分前后模拟器对比验收](./109-拆分前后模拟器对比验收.md)，拆前拆后一致，非本轮重构引入。

## 现象

阅读器正文在懒窗口内连续上滑，到第 3 次上滑后不再推进，焦点停在已加载的懒窗口边界，翻不到后续页面：

- 探测终态：`hitEnd=True`，`swipes=3`；止于 **unit 9 / 第 10 页（共 41 页）/ 第 35 段起**。
- 日志：**无 `scroll window`**（续装未被触发）、**无 `page overflow`**（未判到头）、也无到头播报。
- 对照：`scroll page: unit=8 offset=5965` → `unit=9 offset=6715` 两侧相同，之后再上滑无新日志、树与截图不变。

2s 落定窗定向复测中，上滑 #3 同样卡在 unit 2（第 3 页 / 第 9–12 段），无 `scroll window`、无 unit 3 事件；缺陷边界两侧同位置复现。

## 影响

读者滑到当前已加载窗口末尾后焦点停死：既不续装后续段落，也不播报到头，停在中间页（全书 41 页，实测只走到第 10 页）。这与 [103-正文焦点流滚屏分页](./103-正文焦点流滚屏分页.md)「滚屏即分页、快到末尾按页续装」的设计意图不符——正常情况下贴近窗口末尾应触发续装、继续向后翻页。

## 现状判定

- 拆前基线包（`5ace533`）与拆后包（`c78ad30`）在同一 AVD、同一本书、同一套动作下，卡在同一位置、同一终态，日志集合一致。
- 源码口径（109 §7.4 对照表）：列表模型、`snapshotFlow` 分页监听、续装阈值、显式回顶与滚动物理两侧逐行一致，未见拆分引入的改动。
- **结论：既有缺陷，非本轮拆分回归；本轮不修。**

## 排查线索（只列线索，不下结论）

| 线索点 | 现状口径 | 待核对方向 |
|:---|:---|:---|
| 续装阈值 | `snapshotFlow { firstVisibleItemIndex }.distinctUntilChanged() → onTopSegment`；续装条件 `index >= totalItemsCount - 4 → onNeedMoreSegments()` | 阈值触发时 `firstVisibleItemIndex` 是否真的达到 `totalItemsCount - 4`；窗口只铺了本屏 + 后两页，可见项距窗口末尾是否够 4 项 |
| `onNeedMoreSegments` 接线 | 续装下一 unit，记 `scroll window: +unit=…`；由 Activity 侧供给新段落 | 回调到 Activity 的接线是否在忙/翻译态被拦；续装请求发出后段落是否真正追加进 `segments`，追加后 `totalItemsCount` 是否更新 |
| window 重铺是否回顶 | `LaunchedEffect(scrollToken) { scrollToItem(0) }` 仅在显式换页时回顶 | 续装追加段落时列表是否重铺、首可见项被重置；`scrollToken` 是否被误触发导致回顶 |
| 页表未推进是否拦住续装 | `onTopSegment`：段 → unit → `mOffset = mPageOffsets[unit]`，记 `scroll page: unit=…` | 页表 / unit 未推进时，续装分支是否被当作「已在末尾」短路；`advance`/`gotoUnit` 在窗口边界处的条件判定 |
| 到头判定 | 无 `page overflow` 日志，说明未走到边界溢出分支 | 续装失败与真正到头是否被混在同一终态；缺少「窗口内无更多可装、且未到头」的中间播报 |

## 验收方法（修复后）

模拟器上从第 1 页连续上滑到底，应满足：

1. 页码从第 1 页连续推进到 **第 41 页**；
2. 日志出现 `scroll page: unit=40`（最后一个 unit）；
3. 续装过程中可见 `scroll window: +unit=…` 日志；
4. 到达书末后有到头播报 / `page overflow`，而不是停在中间某页无响应。
