# 102 - 行滑块到头自动翻页（滚屏不再卡在页末）

## 现象

开着连续滚屏（视口首行=光标所在行）之后，把下面那条「第 N 行 / 共 M 行」的滑块拖到最右，
屏上停在「共 M 行」不动，**不会进下一页**；反过来在第一行再往前也没反应。
用读屏上下滑调那一格，同样到底就停住。

## 根因

不是滚屏没生效（内容确实按行在滚，`showPage()` 的 `viewStart` 一路在动），
是**行滑块的取值范围只有「本页」**：

- 语义：`progressBarRangeInfo(index, 0f..maxIndex, steps = count-2)`，`maxIndex = count-1`；
- 触摸：`fraction = ((x - trackStartPx) / span).coerceIn(0f, 1f)`；
- 动作：`moveToPageLine(index)` 里再 `coerceIn(0, mPageLineStarts.size - 1)`。

三处都把「超出去」这句话抹掉了，所以到最后一格就是终点，翻不了页。
用户要的是「继续往前推就滚进下一页」，这是一个**越界意图**，不是本页内的取值。

## 做法

把「按到哪儿 / 调到哪一格」的判定抽成纯函数（`compose/BrailleReaderScreen.kt` 顶层）：

```kotlin
internal data class ScrubberHit(val index: Int, val overflow: Int)

internal fun scrubberHitAt(x, trackStartPx, trackEndPx, maxIndex, overflowEnabled, overflowSlack = 0.04f): ScrubberHit
internal fun scrubberHitForAdjust(index, target, maxIndex, overflowEnabled): ScrubberHit
```

- `overflow = 0`：落在第 `index` 格，照旧 `onSeek`；
- `overflow = +1 / -1`：越过端点，交 `onOverflow(±1)`，由 Activity 翻页。

两处接上：

1. **触摸（含拖动）**：轨终点取 `size.width - radiusPx`（与 Canvas 画的那段轨对齐），
   `raw > 1 + 0.04` → 下一页、`raw < -0.04` → 上一页。0.04 的容差是给「压在轨道最右端的手抖」，
   不然手指一抖就翻页。同一个手势里同方向只翻一次（`over` 记住），避免一口气跳好几页。
   抬起（`!change.pressed`）那一刻的坐标也判一次——快速拖动时中间事件会被合并/丢弃，
   抬起位置才是真正推到的地方。
2. **读屏上下滑（`setProgress`）**：目标被夹回**同一格**就是「到头了还想往前」——
   在本页最后一行 → 下一页，在第一行 → 上一页，中间格原地不动什么都不做。

Activity 侧新增 `onLineOverflow(delta)`：`currentUnit() + delta` 夹在 `0..totalUnits()-1`，
到书的头尾就 `announce()`「已经是第一页 / 最后一页」，否则 `gotoUnit(target)`，新页从第 1 行起铺。
页滑块（`overflowEnabled = false`）保持原样，永不越界。

## 踩过的坑

- `pointerInput(count, maxIndex, trackStartPx, overflowEnabled)`：翻译还在跑时 `count` 会跳变，
  手势被中途重建，拖动只认按下那一刻的坐标（表现为「怎么拖都只到前面几行」）。
  改成 `pointerInput(trackStartPx)` + `rememberUpdatedState` 取最新值。
- `input swipe` / `input motionevent` 在这台机器上抓不到拖动：系统里的读屏服务会把滑动吞掉，
  注入只到 DOWN 就被 CANCEL（日志只有一条 `page line:`），所以拖动分支只能靠单测保证，
  真机上靠读屏上下滑调一格来验收。

## 验收

- 单测 `compose/ReaderScrubberHitTest`（11 条）：两端映射、中点、越界左右、0.04 容差不翻页、
  页滑块不翻页、最后一行再上调 = 下一页、第一行再下调 = 上一页、中间格原地不动。
- 真机：滑到本页最后一行后再往上调一格 → 页号 +1、行号回到 1、内容换到下一页首行。
