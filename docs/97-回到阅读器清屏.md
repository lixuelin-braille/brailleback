# 97 · 回到阅读器先清空点显器

## 问题

从别的界面（聊天、桌面）切回阅读器时，点显器上常常还留着那边的字：
`onPause` 里 `releaseDisplay()` 把点显器交还给服务，服务随后把当前焦点文字的
盲文推上去；再切回来时，`onResume` 新建 `DisplayClient`、重连回调里才 `sendToDisplay()`，
在这段空档里屏上是上一处界面的内容，和本页混在一起摸起来「既不像书也不像聊天」。

## 做法

- `BrailleReaderActivity` 新增 `mClearDisplayOnEnter`，`onResume()` 里置 `true`。
- `onConnectionStateChanged()` 的重连分支（`runOnUiThread`）里，若 `mConnected && mClearDisplayOnEnter`，
  先 `clearDisplay()` 再 `sendToDisplay()`：

```kotlin
private fun clearDisplay() {
    val display = mDisplay ?: return
    val cells = mDisplayCells.coerceIn(1, MAX_DISPLAY_CELLS)
    holdDisplay()                                  // 先冻服务，别让它的文字盖回来
    display.displayDots(ByteArray(cells), "", null) // 全 0 点位 + 空文本 = 整屏空方
    Log.d(LOG_TAG, "display cleared: cells=$cells")
}
```

与 `DisplayManager` 清屏同一做法（`displayDots(ByteArray(cells), "", null)`），
不释放独占，所以紧接着的 `sendToDisplay()` 仍然落在本 App 的页面上。

## 实测（接 30 方点显器）

```
display state=0 connected=false cells=-1
display state=1 connected=true cells=30
display cleared: cells=30
send: from=1943 to=1973 len=30 display=30
```

`KEYCODE_HOME` 离开再 `am start` 回来，`onResume` → 重连 → 先 `display cleared`，随后 `send:` 把本页铺回去，
中断时间从 5 秒缩到 0.05 秒内（清屏与推送同一帧）。

## 另一头：回到书架也清空

阅读器 `onPause` 会把点显器交还服务，屏上留着上一本书的点位；回到书架时不希望再摸到那本书。
于是 `BrailleBackService` 加一个静态入口，书架 `onResume` 直接调用：

```kotlin
@JvmStatic
fun clearDisplayContent() {
    instance?.displayManager?.sendEmptyCommand()   // 全空方，不改冻结状态
}
```

`DisplayManager.sendEmptyCommand()` 本来就有（按 `numTextCells` 发 `displayDots(ByteArray(cells), "", null)`），
这里只是把它暴露给同 App 的界面用。服务没起、点显器没连时静默返回。

书架侧（注意书架入口现在在 `HomeContainerActivity` 的阅读 Tab，`BookshelfActivity` 是旧薄壳，两处都调）：

```kotlin
// HomeContainerActivity.onResume / BookshelfActivity.onResume
controller.refreshList()
BrailleBackService.clearDisplayContent()
Log.d("BrailleShelf", "home clear display")
```

实测（30 方点显器）：从 `HomeContainerActivity` 启动 → 日志 `home clear display`；
打开书 → `display cleared: cells=30`；`KEYCODE_BACK` 回书架 → 又一次 `home clear display`。

## 可调项

现在是「清空 → 立刻铺本页」。如果希望回来时保持**空白**、等按行/翻页键才出字，
把重连分支里的 `sendToDisplay()` 也跳过即可（`mClearDisplayOnEnter` 用完置 `false`，
下次按键的 `moveLine` 会自然把内容铺上）。
