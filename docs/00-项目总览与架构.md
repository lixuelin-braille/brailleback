# brailleback盲文 · 项目总览与架构

> 项目名：**brailleback盲文**（原「盲文迁移项目」，原 Lingxi 林夕读屏）
> 定位：Android 无障碍**盲文辅助**软件，自研中文盲文排版引擎
> 基础：Google BrailleBack（eyes-free 开源）定制
> 文档生成：2026-08-29（基于代码实际审查）；**2026-08-31 更新**（阅读器/书架/翻译模式/文件日志）

## 一、一句话架构

```
Android 界面树 (AccessibilityNodeInfo)
    │  BrailleBackService 监听无障碍事件
    ▼
节点 → 盲文规则 (BrailleRule) → 文本+Span (DisplaySpans)
    │
    ▼
DisplayManager.Content ──► TranslatorClient (AIDL) ──► TranslatorService
                                                          │
                                          ┌───────────────┴───────────────┐
                                          ▼                               ▼
                                  BrailleSegmenter                 LibLouisWrapper
                                  (中文分词规则引擎)                 (JNI → liblouis 3.38)
                                    + JiebaDict                          │
                                          └──────────► 盲文点位 (cells) ◄──┘
                                                          │
                                                          ▼
                                              DisplayService (AIDL)
                                                          │
                                          BrlttyWrapper (JNI → brltty 6.7)
                                                          │
                                    ┌─────────────────────┼─────────────────────┐
                                    ▼                     ▼                     ▼
                              Braille HID          Bluetooth RFCOMM         USB
                           (Android 15+, API35)      (传统串口)            (USB-OTG)
                                    └─────────────────────┼─────────────────────┘
                                                          ▼
                                                    盲文点显器
   输入反向：点显器按键 → brltty → ReadThread → DisplayService → BrailleInputEvent
             → BrailleBackService.onMappedInputEvent → NavigationMode / 全局命令
```

## 二、模块地图

| Gradle 模块 | 目录 | 语言/规模 | 职责 |
|:---|:---|:---|:---|

| `:service` | `service/` | Java 13 + Kotlin 2 + JNI 700 文件 | **盲文服务**：翻译服务(含自研中文引擎) + 点显器连接服务(brltty/HID) |

| `:libraries:utils` | `libraries/utils/` | Java 83 | 通用工具：无障碍节点工具、标签管理、MIDI 播放、LogUtils |
| `:libraries:compatutils` | `libraries/compatutils/` | Java 23 | Android 各 API 版本的兼容封装 |

模块依赖：
```
brailleback ──┬──> client ──> (AIDL 接口，运行时绑定 service)
              ├──> libraries:utils
              └──> libraries:compatutils
service ──────┴──> client（共享 AIDL 数据类）+ libraries:utils
```

> 注意：`brailleback` 与 `service` 是**两个 APK 内的独立服务进程**吗？否 ——
> `service` 以 **AAR 库**形式被打包进 `brailleback`（`:service` 产出 `bundleDebugAar`），
> 二者**同进程**，这也是 `HidBridge` 能用静态变量传递 `BrailleDisplayController` 的前提。
> 所有组件（无障碍服务/阅读器/书架/翻译服务/显示服务）同进程 → 文件日志单进程写入安全。

## 二·五、阅读器/书架（本轮新增，与应用并列的独立入口）

盲文阅读器是**不依赖无障碍服务**的独立界面，复用底层显示管线：

```
bdo/bdoc/brf/brl/txt 文件（含盲文图书馆 12848 本 bdo）
  → BrailleFileDecoder.decodeDocument()      按后缀分派：bdo→BdoCArchiveParser；文本→BOM/UTF-8/GBK
  → detectKind()                             内容类型检测：BRAILLE(点位) / ASCII(BRF) / TEXT(明眼文字)
      ├─ BRAILLE / ASCII ──► toReadingStream()（直接读，ASCII 按 NABCC 转点位）
      └─ TEXT ──► 翻译模式：TranslatorManager ─► TranslatorService（复用无障碍翻译管线）
                    逐段 translate() → cells[] ─► cellsToUnicodeText() ─► toReadingStream()
  → 阅读流（段落 \n 分隔，空行折叠，行首缩进保留）
  → pageOffsets()  边界对齐步进页表（20/30/40 方点显器翻屏不切断字）
  → screenAt()/cellsAt() 屏幕一屏 / 点显器一屏（同起点）
  → DisplayClient.displayDots() ─► DisplayService ─► 蓝牙 ─► 点显器
  → 自动同步点显器；书签/目录/跳页基于字符偏移；进度存 SharedPreferences

BookshelfActivity（书架）：SAF 树授权浏览目录 + ACTION_OPEN_DOCUMENT 单文件导入
  → Intent EXTRA_URI ─► BrailleReaderActivity 直接加载
```

**翻译模式要点**：明眼 txt（盲文图书馆 `02_电子书/` 573 本全为明眼中文）打开后
自动检测并翻译成盲文点位，屏幕与点显器均显示盲文；翻译服务异步绑定未就绪时
挂起请求、就绪后自动继续；翻译失败回落显示原文并提示。

**内容检测规则**（`BrailleFileDecoder.detectKind`，保守启发式，UI 可手动覆盖）：
盲文点位 >50% → BRAILLE；汉字 >20% → TEXT；0x20-0x5F 覆盖 >85% 且非字母特殊符号 >12% → ASCII；否则 TEXT。

## 三、两个"服务"的区分（易混淆）

| 类 | 所在模块 | 类型 | 作用 |
|:---|:---|:---|:---|
| `BrailleBackService` | brailleback | `AccessibilityService` | 读屏主服务：接收无障碍事件、焦点跟踪、导航、把内容送去显示 |
| `DisplayService` | service | `Service` | 点显器连接服务：驱动 brltty、管理 HID/蓝牙/USB 通路 |
| `TranslatorService` | service | `Service` | 翻译服务：文本 → 盲文点位（含自研中文分词） |
| `SelfBrailleService` | brailleback | `Service` | 自建盲文内容通道（其他 App 可向点显器写内容） |

## 四、核心数据流（输出方向）

1. **事件捕获** — `BrailleBackService.onAccessibilityEvent()` 收系统无障碍事件
2. **焦点跟踪** — `FocusTracker` / `FocusFinder` 确定当前焦点节点
3. **节点盲文化** — `NodeBrailler` 遍历节点树，用 `BrailleRuleRepository` 选择 `BrailleRule` 格式化，产出 `DisplaySpans`（文本 + 焦点/选中 Span）
4. **内容封装** — `DisplayManager.Content`（含 `getPanStrategy()` / `getContractionMode()` / `isSplitParagraphs()` / `isEditable()`）
5. **翻译** — `DisplayManager` 经 `TranslatorClient` 调 `TranslatorService.translate()`
   - 含 Unicode 盲文字符(U+2800–U+28FF) → 走**直通**分支
   - 中文表（表名以 `zh` 开头）且分词器就绪 → 走 `BrailleSegmenter` 分词 → liblouis
   - 其他 → 直接 liblouis
6. **排版折行** — `WrapStrategy`（含**避头点/避尾点**国标规则）计算换行/平移断点
7. **输出** — `DisplayService` → `BrlttyWrapper`(JNI) → brltty → 点显器

## 五、输入数据流（反向）

```
点显器按键/滚轮
  → brltty 读取 → ReadThread
  → DisplayService → IBrailleServiceCallback
  → DisplayManager.onInputEvent()
  → BrailleBackService.onMappedInputEvent(BrailleInputEvent)
      ├─ handleGlobalCommands()   全局命令（帮助/返回/主页/音量键映射等）
      └─ NavigationMode          当前导航模式下解释（默认/菜单/搜索/输入法/树调试）
```

| 项 | 值 |
|:---|:---|
| AGP | 9.2.0 |
| Gradle | **9.4.1**（wrapper 用腾讯镜像，下载超时用系统 gradle 绕过） |
| JDK | 17+ |
| compileSdk / targetSdk | 35 / 35 |

| NDK | AGP 默认 28.2.13676358（⚠️ `local.properties` 当前指向 29，见下） |
| 原生库 | 预编译 `.so` 置于 `service/jniLibs/{arm64-v8a,armeabi-v7a}/`（AGP 9 不支持库模块内跑 ndk-build）；已做 **16KB 页对齐**（`-Wl,-z,max-page-size=16384`） |
| 产物 | `brailleback/build/outputs/apk/debug/brailleback-debug.apk`（约 9.9 MB，双架构，debug 签名可直接覆盖安装） |

### 构建命令
```bash
cd /d/软件/brailleback盲文
gradle :brailleback:assembleDebug --rerun-tasks   # 真编译（不带 --rerun-tasks 可能全 UP-TO-DATE）
# 单元测试（纯逻辑层，无设备）
gradle :brailleback:testDebugUnitTest
gradle :service:testDebugUnitTest
# 只编 Java（快，但**不校验 XML 资源引用**——曾漏掉 pref_auto_connect_key 导致打包才炸）
gradle :brailleback:compileDebugJavaWithJavac :brailleback:processDebugResources
```

### ⚠️ 已知环境小问题
- `local.properties` 的 `ndk.dir` 指向 **29.0.14206865**，AGP 默认 `android.ndkVersion` 是 **28.2.13676358**
  → 报 `CXX1104` 版本不一致，`.so` 未 strip，APK 偏大，**不影响运行**
  → 修法：把 `ndk.dir` 改指 28.2.13676358（本机已装），或在 `service/build.gradle` 显式声明 `ndkVersion "29.0.14206865"`
- 首次 `assembleDebug` 可能 8 秒结束、153/158 任务 UP-TO-DATE（Gradle 认为已完成）→ 加 `--rerun-tasks`
- **AIDL 手写桩**：`client/.../display/IBrailleService.java` 是**手写的**（非 .aidl 自动生成），
  加接口方法必须**同时改** `.aidl` 和 `.java`（Stub.onTransact / Proxy / TRANSACTION 常量 / 接口声明）。
  曾因只改 .aidl 导致 `disconnect()` 找不到编译失败。这是本项目最大维护陷阱。

**语言约定**：新增代码一律 **Kotlin**；核心解析/步进逻辑保持**零 Android 依赖**（纯 Kotlin + JVM 单测）；
Google 原版 Java 类（`BrailleBackService`/`DisplayManager`/`LogUtils` 等）**不主动重写**（稳定优先），
新功能以新增文件为主。

**文件日志**：`LogFileWriter.init()` 在无障碍服务/阅读器/设置页 onCreate 各调一次（幂等）。
用户真机出问题时，设置→开发者选项→查看调试日志→分享，即可导出运行日志，无需 adb。

## 十、已知技术债（不急于处理，维护时留意）

1. **老 `android.preference` API**（deprecated）：设置页整个基于 Google 2014 框架，`androidx.preference`
   是官方现代方案。**暂不迁移**：改动面大（整个 preferences.xml + Activity）、收益对盲人用户低、
   当前无测试兜底 UI。触发点：需设置搜索/深色模式问题/必须用新组件时再迁。
2. **手写 AIDL 桩**（`client/.../IBrailleService.java`）：非自动生成，改接口必须 `.aidl` + `.java` 双改。
   加接口时优先仿 `poll()` 的 oneway 写法。
3. **`brailleback` 模块职责偏多**：无障碍服务 + UI + 阅读器 + 书架 + 日志。可拆但收益主要是"整洁"，
   不是功能；在真机验证与翻译质量补齐前**不建议拆**。
4. **无 CI**：构建/测试全靠手动 `gradle`。值得后续加 GitHub Actions 跑 `testDebugUnitTest + assembleDebug`。
5. **真机验证欠账**：16KB 对齐、targetSdk 35、前台服务、Unicode 直通、翻译模式、书架 SAF、
   点显器方数上报显示——全部仅编译期验证，需接设备逐项点测。
6. **`values-zh-rCN` 翻译**：曾缺 `pref_connection_protocol_title`（已补），新增 UI 字串务必中英双写。
