# brailleback盲文 · 项目总览与架构

> 项目名：**brailleback盲文**（原「盲文迁移项目」，原 Lingxi 林夕读屏）
> 定位：Android 无障碍**盲文辅助**软件，自研中文盲文排版引擎
> 基础：Google BrailleBack（eyes-free 开源）定制
> 文档生成：2026-08-29（基于代码实际审查）

---

## 一、一句话架构

```
Android 界面树 (AccessibilityNodeInfo)
    │  BrailleBackService 监听无障碍事件
    ▼
节点 → 盲文规则 (BrailleRule) → 文本+Span (DisplaySpans)
    │
    ▼
DisplayManager.Content ──► TranslatorClient (AIDL) ──► TranslatorService
                                                          │
                                          ┌───────────────┴───────────────┐
                                          ▼                               ▼
                                  BrailleSegmenter                 LibLouisWrapper
                                  (中文分词规则引擎)                 (JNI → liblouis 2.6.0)
                                    + JiebaDict                          │
                                          └──────────► 盲文点位 (cells) ◄──┘
                                                          │
                                                          ▼
                                              DisplayService (AIDL)
                                                          │
                                          BrlttyWrapper (JNI → brltty 6.7)
                                                          │
                                    ┌─────────────────────┼─────────────────────┐
                                    ▼                     ▼                     ▼
                              Braille HID          Bluetooth RFCOMM         USB
                           (Android 15+, API35)      (传统串口)            (USB-OTG)
                                    └─────────────────────┼─────────────────────┘
                                                          ▼
                                                    盲文点显器
   输入反向：点显器按键 → brltty → ReadThread → DisplayService → BrailleInputEvent
             → BrailleBackService.onMappedInputEvent → NavigationMode / 全局命令
```

## 二、模块地图

| Gradle 模块 | 目录 | 语言/规模 | 职责 |
|:---|:---|:---|:---|
| `:brailleback` | `brailleback/` | Java 19 + Kotlin 27 | **主应用**：无障碍服务、导航模式、节点盲文化、折行排版、音效、设置 UI、输入法 |
| `:service` | `service/` | Java 13 + Kotlin 2 + JNI 700 文件 | **盲文服务**：翻译服务(含自研中文引擎) + 点显器连接服务(brltty/HID) |
| `:client` | `client/` | Java 18 + AIDL 10 | **客户端库**：跨进程调用 service 的 AIDL 接口与数据类 |
| `:libraries:utils` | `libraries/utils/` | Java 83 | 通用工具：无障碍节点工具、标签管理、MIDI 播放 |
| `:libraries:compatutils` | `libraries/compatutils/` | Java 23 | Android 各 API 版本的兼容封装 |

模块依赖：
```
brailleback ──┬──> client ──> (AIDL 接口，运行时绑定 service)
              ├──> libraries:utils
              └──> libraries:compatutils
service ──────┴──> client（共享 AIDL 数据类）+ libraries:utils
```

> 注意：`brailleback` 与 `service` 是**两个 APK 内的独立服务进程**吗？否 ——
> `service` 以 **AAR 库**形式被打包进 `brailleback`（`:service` 产出 `bundleDebugAar`），
> 二者**同进程**，这也是 `HidBridge` 能用静态变量传递 `BrailleDisplayController` 的前提。

## 三、两个"服务"的区分（易混淆）

| 类 | 所在模块 | 类型 | 作用 |
|:---|:---|:---|:---|
| `BrailleBackService` | brailleback | `AccessibilityService` | 读屏主服务：接收无障碍事件、焦点跟踪、导航、把内容送去显示 |
| `DisplayService` | service | `Service` | 点显器连接服务：驱动 brltty、管理 HID/蓝牙/USB 通路 |
| `TranslatorService` | service | `Service` | 翻译服务：文本 → 盲文点位（含自研中文分词） |
| `SelfBrailleService` | brailleback | `Service` | 自建盲文内容通道（其他 App 可向点显器写内容） |

## 四、核心数据流（输出方向）

1. **事件捕获** — `BrailleBackService.onAccessibilityEvent()` 收系统无障碍事件
2. **焦点跟踪** — `FocusTracker` / `FocusFinder` 确定当前焦点节点
3. **节点盲文化** — `NodeBrailler` 遍历节点树，用 `BrailleRuleRepository` 选择 `BrailleRule` 格式化，产出 `DisplaySpans`（文本 + 焦点/选中 Span）
4. **内容封装** — `DisplayManager.Content`（含 `getPanStrategy()` / `getContractionMode()` / `isSplitParagraphs()` / `isEditable()`）
5. **翻译** — `DisplayManager` 经 `TranslatorClient` 调 `TranslatorService.translate()`
   - 含 Unicode 盲文字符(U+2800–U+28FF) → 走**直通**分支
   - 中文表（表名以 `zh` 开头）且分词器就绪 → 走 `BrailleSegmenter` 分词 → liblouis
   - 其他 → 直接 liblouis
6. **排版折行** — `WrapStrategy`（含**避头点/避尾点**国标规则）计算换行/平移断点
7. **输出** — `DisplayService` → `BrlttyWrapper`(JNI) → brltty → 点显器

---

## 五、输入数据流（反向）

```
点显器按键/滚轮
  → brltty 读取 → ReadThread
  → DisplayService → IBrailleServiceCallback
  → DisplayManager.onInputEvent()
  → BrailleBackService.onMappedInputEvent(BrailleInputEvent)
      ├─ handleGlobalCommands()   全局命令（帮助/返回/主页/音量键映射等）
      └─ NavigationMode          当前导航模式下解释（默认/菜单/搜索/输入法/树调试）
```

## 六、构建与环境

| 项 | 值 |
|:---|:---|
| AGP | 9.2.0 |
| Gradle | **9.4.1**（wrapper 用腾讯镜像） |
| JDK | 17+ |
| compileSdk / targetSdk | 35 / 34 |
| minSdk | 23 |
| NDK | AGP 默认 28.2.13676358（⚠️ `local.properties` 当前指向 29，见下） |
| 原生库 | 预编译 `.so` 置于 `service/jniLibs/{arm64-v8a,armeabi-v7a}/`（AGP 9 不支持库模块内跑 ndk-build） |
| 产物 | `brailleback/build/outputs/apk/debug/brailleback-debug.apk`（约 9.65 MB，双架构） |

### 构建命令
```bash
cd /d/软件/brailleback盲文
gradle :brailleback:assembleDebug --rerun-tasks   # 真编译（不带 --rerun-tasks 可能全 UP-TO-DATE）
```

### ⚠️ 已知环境小问题
- `local.properties` 的 `ndk.dir` 指向 **29.0.14206865**，AGP 默认 `android.ndkVersion` 是 **28.2.13676358**
  → 报 `CXX1104` 版本不一致，`.so` 未 strip，APK 偏大，**不影响运行**
  → 修法：把 `ndk.dir` 改指 28.2.13676358（本机已装），或在 `service/build.gradle` 显式声明 `ndkVersion "29.0.14206865"`
- 首次 `assembleDebug` 可能 8 秒结束、153/158 任务 UP-TO-DATE（Gradle 认为已完成）→ 加 `--rerun-tasks`
