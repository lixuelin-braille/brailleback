## 2. P2-1 线宽归一：三态门控与生产接线

### 2.1 三态语义

| 模式 | 行为 | 用途 |
|---|---|---|
| `OFF` | 不跑归一，`normalize` 原样返回输入数组（同一引用，不复制不改写） | 对比 / 回归基线 |
| `AUTO`（默认） | 依次过门控①②，都命中才加固；任一不命中原样返回 | 生产成书链路 |
| `FORCE` | 绕过两道判定直接处理 | 仅调试 / 度量对照，生产入口不提供 |

### 2.2 AUTO 两道门控（均为可单测纯函数）

**门控① 纯线条图 `isPureLineArt(ink, cols, rows)`**：
- 墨点占比 > `MAX_INK_RATIO = 0.35` → 非线条图；
- 2×2 实心块占比 > `MAX_SOLID_BLOCK_RATIO = 0.08` → 非线条图；
- 全白图视为纯线条图。

**门控② 断裂迹象 `hasFragmentationSign(ink, cols, rows)`**，任一命中即有断裂：
- 8 邻域墨点 ≤1 的孤立点 ≥ `MIN_ISOLATED_DOTS = 8`；
- 4 邻域大小为 1 的单格连通域 ≥ `MIN_SINGLETON_COMPONENTS = 5`。

> 完整闭合轮廓（圆 / 方框 / 心形 / 字母 A）孤立点为 0、无单格碎域，门控②不命中 → 逐字节不变；断线图（箭头 / 房屋）散出一串孤立点，门控②命中才进入加固。

### 2.3 加固流程（门控命中或 FORCE 时）

1. **断线搭桥**：孤立 / 近孤立墨点沿 8 个方向在 `MAX_BRIDGE_GAP = 4` 格内寻找另一头墨点，方向线段上的空格补齐；只补断线空隙，不延长线端；新点不得构成新 2×2 实心块。
2. **连通域粗细约束**：4 邻域标号；含 2×2 实心块的连通域判粗块，整域不参与补点。
3. **方向感知单侧补点**：横笔画只补下方、竖笔画只补右方，1 点宽补到 2 点宽，不双侧外扩成 3 点宽；夹在两条平行笔画之间的空隙不填补。
4. **兜底**：新增墨点超 `maxGrowthRatio = 2.0`（相对原墨点）放弃本轮；`maxPasses = 1`。

### 2.4 生产接线位置

`TactileStripSession.build`：`ImageStripEncoder.dotGrid` 得到 `rawInk` → `TactileStrokeNormalizer.normalize(rawInk, …, Config(mode = normalizerMode))` → 归一后的点阵再进 `TactileStripSlicer.slice`。单行视口链路（`buildViewport`）本轮不改归一，仍按原点阵出视口。

## 3. P2-2 标签检测 → 独立图例页（沿用上一轮口径）

- 链路：`buildViewport`（IO 线程）`TactileLabelDetector.detect` 扫候选 → `TactileLegendPage.labelSourceLines` 合成源行 → `TactileStripCaptionBridge.toBraille` 缓存盲文 → 图例屏 `build` 打包下发；失败静默回退空图例。
- 位置口径：带号 = `box.y / bandRows + 1`；方号 = `box.x / 2 + 1`（1 基，钳制 `1..cellsPerLine`）。
- **墨迹保留不擦除**：无 OCR，无法区分标注与图形细节，擦除会丢图；图例页只说明位置。
- 措辞边界：只报「标注位置」，不声称识别「标注文字 / 内容」。

## 5. P2-4 G1 多行封面分层

### 5.1 布局规则（仅 `linesPerScreen >= 2` 生效）

- 图形带压到屏幕**第 2 行起**，图形区每页行数 = `linesPerScreen - 1`；封面只写第 1 行（`cellsPerLine` 方），其余行清零；装不下则多屏，每屏仍只用第 1 行。
- 切片按少一行版面切，成书摆回整屏第 2 行起；`bandRows = (linesPerScreen - 1) × dotRows`，`totalBands` 与封面「共 N 带」一致。
- **封底整屏保留**：结束提示屏不向图形让行，四项文案整屏铺开。

### 5.2 开关与透传

| 层 | 开关名 | 默认 | 说明 |
|---|---|---|---|
| Activity 状态 | `g1SplitCover` | `false` | 参数页「多行：封面占首行」单选；单行设备置灰不可点 |
| `TactileStripSession.build` | `g1SplitCover` | `false` | 经 `g1Effective(开关, spec)` 解析：开关打开且多行才生效 |
| `TactileStripBookBuilder.build` | `g1` | `false` | 成书分层摆位 |

关闭（默认）既有 40×4 整屏三段式**逐字节不变**；单行设备 G1 自动忽略。透传断言见 `TactileStripSessionOptionsTest` 与 `TactileStripG1LayoutTest`。
