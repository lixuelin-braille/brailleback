## 拆出了哪些文件，各自职责

### 1. `BrailleLanguagesLocales.kt` —— 语言标签常量

- `Locale.forLanguageTag("ar")`、`"en-IN"`、`"yue"`、`"sd-IN"` 等标签字面量逐条保留；
- `Locale.GERMAN` / `Locale.ENGLISH` / `Locale.UK` / `Locale.US` / `Locale.FRENCH` / `Locale.ITALIAN` / `Locale.JAPANESE` / `Locale.KOREAN` / `Locale.SIMPLIFIED_CHINESE` / `Locale.TRADITIONAL_CHINESE` 等内置实例原样保留；
- 常量名、顺序、取值零调整。

### 2. `BrailleLanguageEditBuffers.kt` —— 条目 EditBuffer 装配派发

原枚举里 34 个条目以匿名对象覆写 `createEditBuffer`；拆分后这些装配体逐字搬到本文件的同包扩展函数：

```kotlin
internal fun BrailleLanguages.Code.codeEditBuffer(
    context: Context,
    talkBack: TalkBackSpeaker,
    translator: BrailleTranslator,
    contractedMode: Boolean,
): EditBuffer {
    return when (this) {
        BrailleLanguages.Code.ARABIC -> { ... }
        ...
        else -> EditBufferUnContracted(context, translator, talkBack)
    }
}
```

- 分支顺序与原条目顺序一致；
- 每个分支体内的判断（ contracted 与否）、返回的 EditBuffer 类型、行内注释（含中文音节切分注释、`Based on Russian.`）原样保留；
- 枚举默认实现由 `codeEditBuffer` 回落承担，未覆写条目仍走 `EditBufferUnContracted`，行为不变。

### 3. `BrailleLanguages.kt` —— 门面入口

保留对外 API：

- `createEditBuffer(context, talkBack, code, translatorFactory, contractedMode)`：先建 `BrailleTranslator`，再交条目装配；
- `getAvailableCodes(context)`：遍历 `Code.values()` 过滤可用；
- `extractAvailableCodes(context, codes)`：在可用清单内再按给定集合取交集；

## 清单零漂移怎么保证

对账方式：以拆分前备份 `BrailleLanguages.kt.orig` 为基线，脚本逐条解析枚举条目，与拆分后文件按条目名、顺序、四个构造参数 token 序列比对；另对 58 个标签常量做字面量比对。

- **条目规模**：92 个条目，拆前拆后计数一致；
- **条目顺序**：名称序列逐字相同（`ARABIC, ARABIC_COMP8, BULGARIAN, …, WELSH, STUB`）；
- **构造参数**：locale 常量引用、`R.string.code_user_facing_name_*` 资源、`supportsContracted` 布尔、`eightDot` 布尔逐 token 一致；
- **标签常量**：58 个 `LOCALE_*` 的标签字符串与内置实例引用一致；
- **装配体**：34 个覆写分支的语句逐字搬移，默认回落 `EditBufferUnContracted` 保留；
- **回落链**：英文 → `UEB`；语言匹配 → 国家匹配 → 首个；兜底 `UEB`，未改判定顺序。

> 本文件不含 liblouis 表文件名（`.ctb` / `.utb`）字面量；表清单与表包完整性由 service 侧 `TableArchiveContractTest`、`CbsFullTableSupersetTest` 守门，本次拆分未触碰表清单条目、语言 id 与显示名。

## 踩到的坑

- **嵌套类型别名不可用**：Kotlin 的成员级 `typealias` 是实验特性，需 `-Xnested-type-aliases` 编译器参数；按约束不改 Gradle 配置，因此枚举 `Code` 保持嵌套在 `BrailleLanguages` 内，没有用类型别名把枚举挪到顶层文件。
- **行内注释吃掉后续参数**：原 `RUSSIAN` 条目的 contracted 参数带行内 `// Contracted.` 注释；条目参数紧凑合并排版时，该 `//` 会把同一行后续的 eightDot 参数注释掉。含行内注释的条目回退为逐行排版，其余条目按紧凑排版。
- **表达式体函数内禁止 return**：派发函数最初写成 `= when (this) { ... }` 表达式体，分支内 `return` 被编译器拒绝；改为块体 `{ return when (this) { ... } }`。
