### P1（主流程可见缺陷，需下一轮修复）

#### P1-1　线性函数名后括号实参被静默丢弃（`sin(x)` 只剩 `sin`）

- 级别：P1
- 复现步骤：
  1. 书架 → 数学公式转盲文；
  2. 输入 `sin(x)`，点“转换”；
  3. 查看结果盲文与状态行。
- 期望：`⠫⠎⠣⠰⠭⠜`（函数名 + 括号 + 实参 x）。
- 实际：`⠫⠎`，实参 `(x)` 整段丢失；状态行仍报“转换完成”，**无任何告警**。
- 重复次数：1 轮内稳定复现（B1-4）。
- 根因定位（只读核对，未改）：`math/LinearMathParser.kt:189-193`，`parseFactor` 的 `Tok.Ident` 分支只消费标识符，不解析其后的 `LParen` 函数调用；括号内实参残留到行尾未做校验 / 报错。MathML 路径由 golden `sin(x)` 用例覆盖为正确，缺陷仅限线性解析。
- 证据：`dump/B1-4.xml`、`screenshots/B1-4.png`、`logcat/B1_linear.log`。
- 关联：同类形态 `f(x,y)` 在 JVM golden 中期望 `⠰⠋⠣⠰⠭⠐⠀⠰⠽⠜`，线性路径同样应支持。

#### P1-2　阅读器 TEXT 源正文逐格重复汉字（屏显与源文不一致）

- 级别：P1（待新导入样本二次确认；当前基于既有书 `cbs_test.txt`）
- 复现步骤：
  1. 书架点开 `cbs_test.txt`；
  2. 对比屏显正文与 `/sdcard/Download/cbs_test.txt` 源文。
- 期望：屏显回显原文汉字，一字一显。
- 实际：源文 `国家通用盲文测试。`，屏显 `国国国国国国通通通通盲盲文文测测测试。。…`，每个汉字按其占用的盲文格数被重复多次。

以下现象导致部分用例 BLOCKED，记录在案，避免误判为应用问题：

1. **输入法子类型干扰**：Gboard 默认激活中文拼音子类型，`input text` 注入的字母被转成汉字候选；移除拼音子类型后英文直输可用，但设置会被 IME / 应用重启部分恢复。测试结束已把拼音子类型恢复回设备设置。
2. **`input text` 含 `<` / `>` 或长串（约 160 字符以上）会挂起**；MathML 无法经键盘直输。
3. **adb shell 间歇挂起**：bulk DEL 循环、键盘可见时 BACK、键盘可见时 `uiautomator dump`、部分 `input tap` / swipe 会让 shell 阻塞；恢复手段为停后台任务 → `adb kill-server` → `start-server`。截图（screencap + pull）稳定可用，uiautomator dump 间歇可用。
4. **`am restart <pkg>` 会触发整机重启**，本轮已避免再次使用。
5. **DocumentsUI 网格项在无障碍树中无文件名文本**，自有样本缩略图与文件名无法可靠对应，导致定向选图受阻。
6. shell 无权读取剪贴板内容（Android 12+ 限制），复制结果以 Toast + 工具栏可见片段佐证。
