**F1. 提交并完善电子盲文直通**

- 价值：打通 `/d/软件/盲文图书馆` 的电子书显示

**F2. 真实设备联调（HID + 蓝牙）**

- 待办：抓 `adb logcat`，重点看 `HidBridge.isAvailable()` / `HidDisplayConnection` / native `hid_android.c`

**F3. 分词质量回归**
- 现状：早期在 5,030 万字语料上「基本可用率 100%」，但仍有普通多字词被切开
- 待办：拿真实书籍语料跑一遍 → 收集错切词 → 批量补进 `CONNECT_ARR` 或 `jiebadt.txt`
- 详见 [05-中文盲文引擎详解](./05-中文盲文引擎详解.md) 第五节

### 🟡 第二梯队：体验完善

**F4. 恢复"逐事件自定义音效"**
- 现状：被移除，只剩内置方案整体切换
- 改法：重做 `SoundSchemeManager`(154) + 偏好存储结构

**F5. 六点/八点盲文表智能选择 ✅ 已完成**
- 原 TODO 在 `TranslatorManager.kt`（updateTranslators）已消项：六点模式下 uncontracted 翻译器改取同语种 grade 最小的六点表
- 修复的实害：uncontracted 用于搜索模式逐键反译，旧逻辑强制八点表——中文等六点语种没有八点表，会静默回退到英文表，搜索输入全错。上游 TODO 称需改 IME，但本项目 IME 已改用 `getTranslator()`（文学盲文），前提不成立
- 实测：zh_CN locale 下日志确认选 `zh-CN-cbs`（旧逻辑会回退英文表）；en_US 选 `en-US-g1`
- 附带可观测性：updateTranslators 新增 `Uncontracted table for <locale>: <表id>` DEBUG 日志

**F6. 分词器就绪状态可见**
- 目前静默降级，建议在设置里或日志里暴露状态，便于排查"盲文没分词"的问题

### 🟢 第三梯队：架构优化（不急）

**F7. compatutils 逐步迁 AndroidX** —— 23 个 compat 类中部分已被 `androidx.core` 覆盖
**F8. MIDI 库现代化** —— `com.leff.midi`（38 文件）较老，可评估换现代音频 API
**F9. 词典加载优化** —— 5 MB 词典全量载入内存，可考虑懒加载/裁剪/预编译二进制

## 五、调试速查

```bash
# 构建（注意 --rerun-tasks，否则可能全 UP-TO-DATE 不出包）
cd /d/软件/brailleback盲文
gradle :brailleback:assembleDebug --rerun-tasks

# 安装
adb install -r brailleback/build/outputs/apk/debug/brailleback-debug.apk

# 关键日志 tag
adb logcat -s SegDebug          # 分词前后对比（IN / OUT）
adb logcat -s BrailleSegmenter  # 分词器就绪/失败
adb logcat -s JiebaDict         # 词典加载 words=xxx
adb logcat -s TranslatorService # 表解压 / 翻译降级
adb logcat -s DisplayService    # 点显器连接
adb logcat -s BrailleBackService
```

**常见现象 → 排查方向**
| 现象 | 先看 |
|:---|:---|
| 盲文没分词（逐字） | `JiebaDict` 的 `dict loaded` 是否成功；`mSegmenterReady` 是否为 true |
| 光标位置错乱 | 分词插入空格后的坐标还原（`translateWithSegment` 的 `origToSeg`/`segToOrig`） |
| 电子书乱码 | Unicode 直通分支是否生效（`containsBrailleUnicode`） |
| 点显器连不上 | `HidBridge.isAvailable()`（需 Android 15+ 且 controller 非 null）；`DeviceFinder` 是否发现设备 |
| HID 无输出 | `HidDisplayConnection` / native `hid_android.c`；参考 `/d/软件/brailleback-master/hidverify*.log` |
