## 2. dotColumns 核对（要求项）

`ImageStripEncoder.Spec.forDisplay(...)` 固定 `dotColumns = cellsPerLine × 2`，阈值走 Otsu：

| 方数 | dotColumns | 一行方数上限 |
|:---|:---|:---|
| 20 | 40 | 20 |
| 30 | 60 | 30 |
| 40 | 80 | 40 |

**结论：已铺满整行。** 旧默认 `dotColumns = 64` 时，40 方一行只有 64 点列，只能填满 `64 / 2 = 32` 方，右侧 `40 − 32 = 8` 方永远读不到像素；该问题在核心层已修正为 `cellsPerLine × 2`，本矩阵即按修正后的口径跑出。

## 3. 分级定义

| 级别 | 判据 |
|:---|:---|
| ✅ 可辨 | 跨带拼合后闭合轮廓 / 关键特征完整，凸起密度足够，有经验的触摸者无需预先知道图形也能认出类别 |
| ◐ 勉强可辨 | 轮廓有碎片但断裂、稀疏或特征不全；需要结合上下文、跨带记忆和触摸扫掠才能推断，首次接触易误判 |
| ✗ 不可辨 | 判别性特征丢失，输出只剩横杠 / 点簇 / 满格块，无法区分具体形状 |

## 6. 逐类观察与原因

### 6.1 方框：最耐采样，直角直线最容易保留
- 四边都是水平 / 垂直直线，点格采样时每一行 / 列都能落到笔画上；40×4 与 20×4 的 8 / 6 点全部 ✅。
- 40×1 单行设备只剩「两条竖边 + 末带一条横边」，顶边要翻回首带才摸得到，降为 ◐。
- 4×3 极小屏横向仅 8 点列，采样后只剩底边与右边，缺三边，✗。

### 6.2 圆：大版面 8 点可辨，压窄或单行后轮廓发散
- 40×4 ·8：顶弧、左右弧、底弧分带衔接，环的闭合感在，✅。
- 6 点去掉每方第 4 行（dot7/8），环变细、局部断点增多，◐；20 方下左右弧被压窄，同样 ◐。
- 单行屏把圆弧切成水平条带，上下连续性只能靠跨带记忆；6 点 + 单行进一步丢段，✗。

### 6.3 箭头：三角斜边最脆弱，20 方以下只剩一条横杠
- 判别箭头靠「箭杆 + 闭合三角头」。三角斜边是斜线，低采样率下断成孤立点；40×4 下箭杆完整、箭头只剩零散点，◐。
- 20×4 时三角头基本消失，仅剩横杠（18 方 / 68 点，仅 1 个非空带），无法判断方向，✗。
- 单行与 4×3 规格下箭头完全不可辨。

### 6.4 心形：双瓣 + 收尖可拼合，但细节依赖多点密度
- 40×4 / 20×4 下两瓣上缘与底部收尖仍可辨认，◐；瓣间凹陷与轮廓粗细在低方数下变模糊。
- 单行屏内轮廓无法自洽闭合，✗；4×3 下样本塌成点簇或近满格块，✗。

### 6.5 房屋轮廓：屋顶三角 + 双墙 + 底线，稀疏点线勉强成形
- 20×4 下墙身竖线断成单点列、屋顶脊线为斜线点串，24 / 28 方密度偏低，需脑补，◐。
- 屋顶三角在单行屏内无法在一屏内呈现，✗；极小屏只剩 4~6 个方，✗。

### 6.6 字母 A：顶点 / 横杠 / 斜腿三要素，低分辨率下斜腿断续
- 40×4、20×4 下顶点、横杠块与两条斜腿可辨，◐；6 点下斜腿断点更多，仍在勉强档。
- 字形是上下结构，单行切片后横杠与斜腿分到不同带，单带内不成字，✗；极小屏 ✗。

### 6.7 简单平面图：外墙框可辨，隔墙 / 门洞 / 动线是第二层级信息
- 40×4 ·8 外墙与一条隔墙可见，97 方；门洞缺口、入口动线在采样后很弱，首次触摸难判断房间邻接，◐。
- 20×4 隔墙变细、动线几乎丢失，◐；单行屏无法表达房间相邻关系，✗；4×3 满格成块，隔墙与外墙混淆，✗。

## 7. 规格维度结论

1. **方数（横向分辨率）**：40 方 > 20 方 >> 4 方。方数减半，斜边上的采样点按比例丢失，曲线与斜线最先受损；4 方（8 点列）只适合极简单符号，本批 7 类图形全部 ✗。
2. **行数（纵向版面）**：多行屏（4 行）让闭合轮廓能在连续几行内成形；单行屏（1 行）把图形拆成 20 / 27 条水平带，形状理解完全依赖跨带翻页记忆，复杂图形整体不可辨。
3. **6 点 vs 8 点**：6 点每方纵向少一行（无 dot7/8），曲线 / 斜腿在方内更挤、断点更多；同一点格凸点总数相同，但 6 点凸起方数往往更高（信息被压进更少的纵向行）。直线为主的方框对 6 点不敏感，曲线与斜线形状降级更明显。
4. **形状耐采样排序**：直角直线（方框）> 闭合曲线（圆、心）> 斜线主导（箭头三角、屋顶、字母斜腿）> 多元素布局（平面图）。
5. **当前链路不做放大重排**：图比一屏宽 / 高时按点格切段，不缩放、不裁掉内容；样本若是窄长线条图，单行屏的可读性会比这批 100×100 方形样本好，本矩阵结论不外推到宽幅示意图。

## 8. 局限与待验证（明确划分）

- **已完成（代码 + 离线）**：Activity / 入口 / 接线见 UI 包交付清单；本矩阵的 harness、指标统计、ASCII 预览、dotColumns 核对与分级表均基于离线真实编码器输出，`testDebugUnitTest` 通过、`assembleDebug` BUILD SUCCESSFUL。
- **未做（实机）**：
  - 分级依据是离线 ASCII 预览与凸点 / 方数指标，**尚未在真实盲文点显器上触摸验证**；触觉识别率受点显间距、行高、用户经验影响，离线级别可能偏乐观或偏保守。
  - 样本为程序化合成的干净描边图；照片、扫描件、灰度对比弱、笔画更细的真实图片尚未跑矩阵。
  - 封面 / 封底盲文文字屏的朗读与翻译服务可用性，需在带盲文服务的环境上实测。
